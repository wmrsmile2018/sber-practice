# LESSON-5 — Работа с useRef в React

Ветка: lesson-5

## Запуск

npm ci && npm run dev
npm run build

## Чек лист

Время первого клика фиксируется через ref — 1 балл.
Счетчик кликов хранится в ref, не вызывая ререндер — 1 балл.
В консоли отображается разница во времени и общее количество — 1 балл.
Текущее значение отслеживается через onChange — 1 балл.
Предыдущее значение сохраняется через ref — 1 балл.
UI корректно отображает предыдущее значение — 1 балл.
Установка фокуса работает через ref.current.focus() — 1 балл.
Переход фокуса отслеживается через onFocus — 1 балл.
Количество фокус-переходов корректно отображается в консоли — 1 балл.
